自己架設

  1. git clone https://github.com/Lingo1516/paper-summarizer.git
  2. 把 worker.js 部署到 Cloudflare Workers（免費額度）
  3. 在 Worker 設定環境變數：API_KEY=sk-....（OpenRouter API Key）
  4. 開啟 index.html，填入 Worker 網址即可使用

💡 推薦使用現有 Worker：
已部署好的版本：https://你的-worker-name.workers.dev
或直接用這個：載入中...
