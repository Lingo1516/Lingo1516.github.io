為什麼需要 Paper Summarizer？

⏱️

節省閱讀時間

不用花 30 分鐘讀完整篇論文，30 秒掌握核心內容與發現。

🌐

中英雙語支援

上傳英文論文，產出中文摘要；或上傳中文論文，產出英文摘要。

📊

多格式輸出

支援 JSON、Markdown、HTML 三種格式，方便整合進你的工作流。

💻

開源自由

MIT License，可自由修改、部署、整合到你自己的系統中。

🔒

隱私安全

所有處理都在本地或你控制的伺服器上進行，論文不會外洩。

🎓

學術研究必备

文献综述、会议准备、快速筛选题目，研究效率倍增。

🚀 快速上手

三行命令，在自己電腦上運行 Paper Summarizer

bash 
git clone https://github.com/Lingo1516/paper-summarizer.git
cd paper-summarizer
pip install -r requirements.txt
python app.py

需要 OpenAI API Key：export OPENAI_API_KEY="sk-..."
