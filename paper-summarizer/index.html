自己架設

  1. git clone https://github.com/Lingo1516/paper-summarizer.git
  2. cd paper-summarizer && pip install -r requirements.txt
  3. export LLM_API_KEY="sk-..." （OpenRouter 或其他 OpenAI 相容 API）
  4. uvicorn api:app --host 0.0.0.0 --port 8010 啟動 API
  5. streamlit run app.py 啟動網頁介面（可選）
