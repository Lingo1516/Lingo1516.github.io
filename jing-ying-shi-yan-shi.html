📚 名詞白話教室（一）：公司的家底

每一家公司開局都一樣：現金 $500,000、設備 $500,000、原料 6,000 單位、負債 $200,000。

💰 資產公司擁有、值錢的東西。現金、設備、原料、成品，全部加起來就是資產。
小例：資產 = 500,000（現金）+ 500,000（設備）+ 60,000（原料）+ 0（成品）= $1,060,000
💵 現金口袋裡能立刻花的錢。賣貨收到的錢會進現金；買原料、付廣告、付人工會從現金出去。
注意：公司「有賺錢」不等於「有現金」，錢可能卡在存貨裡。
🏭 設備工廠的機器，決定你能做多少貨。設備用帳面價值計算，會慢慢折舊變舊。
小例：設備 $500,000，每 $125 的設備 = 每期 1 單位產能，所以開局每期最多生產 4,000 單位。
🧱 原料做產品的材料，用「單位」算數量、用「元」算價值。本期新買的原料要下一期才能用。
📦 成品存貨做好了、還沒賣掉的產品。每個市場分開存放，北部的貨不能拿去南部賣。每單位每期要付 $2 保管費。
🏦 負債公司欠別人的錢。開局每家公司都先向銀行借了 $200,000。
小例：負債 200,000，每期利息 = 200,000 × 2% = $4,000，不管這期有沒有賺錢都要付。
👤 業主權益扣掉欠的錢，公司真正屬於股東的淨值。權益 = 資產 − 負債。開局權益 = 1,060,000 − 200,000 = $860,000。賺錢權益會變大，虧錢會變小；權益 ≤ 0，公司就停業。
資產 = 負債 + 權益

📚 名詞白話教室（二）：經營過程中會遇到的詞

📊 單位數量就用「單位」，不要跟錢搞混。售價、預算、費用都用元。
小例：「配貨 800」是 800 單位產品；「售價 100」是每單位賣 $100；800 單位全賣掉，收入 = 800 × 100 = $80,000。
⚙️ 產能這一期工廠最多做得出的數量。
產能 = 期初設備 ÷ 125（向下取整）
小例：設備 500,000 ÷ 125 = 4,000 單位。四個市場的配貨加起來超過 4,000，系統會按比例自動調低。
🔄 材料利用率做產品時原料的耗損程度。
利用率 = min(0.95, 0.8 + 維護費 ÷ 1,000,000)
小例：維護費 5,000 → 利用率 80.5%。想生產 3,200 單位，需要原料 = 3,200 ÷ 0.805 ≈ 3,975 單位，不是 3,200 單位。
⏰ 採購時差本期買的原料，下期才能用。這是最容易踩的規則：本期生產只能用「期初就有的原料」。
🚨 緊急採購原料不夠時，系統自動用貴 50% 的價格補。
小例：不足 1,975 單位 × $10 × 1.5 = $29,625，直接從現金扣。
📉 銷貨成本賣掉的那些產品，當初做它們花了多少。
每單位成本 = （材料費 + 人工 $20）÷ 生產量
🔧 折舊設備變舊的價值損耗，每期固定扣。
折舊 = 期初設備 × 2.5%
💳 保管費成品每單位每期 $2、原料每單位每期 $0.2、管理費固定 $20,000／期。
💼 所得稅有賺錢才課，稅率 20%。虧損不課稅，也不能留到下期抵。

📚 名詞白話教室（三）：成果怎麼看、名次怎麼算

💰 營收這一期賣貨收到的錢。
營收 = 每個市場「成交數量 × 售價」加總
🎯 淨利營收扣掉所有成本與費用、再扣稅之後，真正賺的錢。
稅後淨利 = 營收 − 銷貨成本 − 各項費用 − 稅
🪙 股利把賺到的錢發給股東。限制：不能超過當期可用現金，也不能超過累積盈餘。
📈 NPV（淨現值）八期結束的總評分，排名看它。
NPV = 各期股利折現合計 + 期末權益 ÷ 1.02^期數 − 860,000
📊 市場需求每個市場的需求由基本量、季節、成長與情境共同決定，再依各公司的「吸引力」比例分配。
⭐ 吸引力與價格敏感度吸引力由售價、行銷（廣告）與品質決定。price sensitivity越高，漲價跑掉的客人越多：
市場價格敏感度品牌權重性格一句話
北部1.7（最高）0.2（最小）最怕貴，廣告效果最小 — 拚價格的地方
中部1.30.3價格與品牌都要顧
南部1.00.4品牌開始比價格重要
海外0.7（最低）0.5（最大）最不怕貴、最吃品牌 — 拚毛利的地方
🎨 品質研發慢慢養出來的吸引力。
下期品質 = min(1.6, 品質 × 0.99 + 研發 ÷ 1,000,000)
🛑 停業 — 三條紅線，碰到就出局
1. 權益 ≤ 0
2. 負債超過權益的 10 倍
3. 借到上限現金還是負的

🎮 怎麼使用這套教材：兩種模式、一套節奏

模式一：自主練習（一個人）

  • 你經營一家公司，對手是三家電腦公司（青禾製造、日序企業、遠山實業）
  • 共八期，填完決策按提交就立刻結算
  • 進度存在瀏覽器裡，可下載 CSV 保存
  • 市場情境固定為「正常市場」

模式二：班級競賽（老師 + 各組）

  • 老師開班、拿到班級代碼；每組一位代表用代碼加入（最多 12 組）
  • 共八期，情境由老師設定，全班面對同一個市場競爭
  • 各組交齊決策後，由老師統一結算 — 學生自己不能結算

每一期的固定節奏（五個步驟）

  1. 看情報：經營總覽 — 本期情境、自己的現金、產能、期初原料與各市場庫存、對手排名
  2. 做決策：小組討論後填 18 項決策
  3. 寫理由：一段話寫下「這一期想達成什麼、為什麼這樣配置」
  4. 等結算：班級模式要等全班交齊、老師按下統一結算
  5. 讀報表：看損益表、資產負債表、現金流量表與白話診斷

✋ 學生動手範例

第一步：先算產能、原料、現金

情境：第一期，正常市場
期初家底：現金 $500,000、設備 $500,000、原料 6,000 單位、負債 $200,000
計畫產量：北部 900、中部 800、南部 800、海外 900
產能計算產能 = 500,000 ÷ 125 = 4,000 單位。計畫產量 = 3,400 ≤ 4,000 ✅
原料計算維護費 20,000 → 利用率 = 0.82，需原料 = 3,400 ÷ 0.82 ≈ 4,147 ≤ 6,000 ✅
還剩約 1,853 單位，下期需補約 2,300 單位，保險一點買 3,000 單位（$30,000）
現金計算採購 30,000 + 人工 68,000 + 行銷 26,000 + 維護 20,000 + 研發 10,000 + 管理費 20,000 + 利息 4,000 = $178,000

學生繳交前自查

  • 四市場配貨總和 ≤ 產能？
  • 原料需求（產量 ÷ 利用率）＜ 期初原料？
  • 本期採購有算下期的量嗎？
  • 預估支出 ≤ 期初現金 + 保守收入？
  • 缺貨補了、剩貨減了嗎？理由寫了目標與預測嗎？

老師結算前自查

  • 本期情境設定正確嗎？
  • 公告與指派題目都發了嗎？
  • 繳交組數 = 全部組數嗎？
  • 結算後要帶看的 1–2 組診斷選好了嗎？上期回饋寫了嗎？
